49. Request Transformer
=======================

This plugin will transform the request sent by a client on Kong before hitting the upstream service. So, the upstream service will get a modified request. We can change the HTTP method. For example, the original request is using POST but we transform it so the upstream service request is PUT. We can remove, rename, replace, add, or append request body, headers, or query string. - request-transformer.png

Refer to the Kong plugin documentation page for a detailed explanation of removing

The following sample is quite simple and will show basic usage.

Test Provided Request
---------------------
Use request Postman / Course Content ? REST API Serives / Alpha / POST Alpha Echo
In Params tab we have configured 2 Query Params
	- Key: q-dummy-one
	- Value: q-value-one
	- Key: q-dummy-two
	- Value: q-value-two

In Headers tab we have additional Header configured
	- Key: x-dummy
	- Value: x-value

We have configured body as follow:
--------------------------------
{
	"test" : "kong"
}
--------------------------------

When we send the request we receive response with status code 200 OK

Configre Request Transformer Plugin in  Alpha Service
-----------------------------------------------------

Go to Kong Manager http://localhost:8002/services / Alpha / Plugins / + New Plugin / Request Transformer
	- remove.querystring: q-dummy-one			# remove query param
	- rename.querystring: q-dummy-two:q-dummy-ten		# rename query param
	- replace.headers: x-dummy:x-new-value			# replace header
	- add.body: source:kong					# add body
	- add.headers: x-dummy-kong:x-kog-value			# add header
	- append.body: test:king
	- Install

50. Response Transformer
========================

This plugin will transform the response sent by the upstream service on Kong before returning the response to the client. So the consumer will get a modified response We can remove, replace, add, or append response body or headers. Note that the response body to be modified must be in JSON format. - response-tranformer.png

Refer to the Kong plugin documentation page for a detailed explanation of removing, replacing, or other transformations.

Send provided request Postman Course Content / REST API Services / Alpha / GET Alpha Random Employee

Response body:
------------------------------------
{
    "email": "ares@athena.com",
    "name": "Ares",
    "salary": 9590
}
------------------------------------



Configure Response Tranformer Plugin
------------------------------------

Go to Kong Manager http://localhost:8002/services / Alpha / Plugins / + New Plugin / Response Transformer
	- remove.json: salary
	- replace.json: email:customer.service@olympus.com
	- add.headers: x-type:Greek Gods
	- add.json: 
		- power:immortal
		- age:9999
	- append.json: power:srtong
	- Install



Send provided request again Postman Course Content / REST API Services / Alpha / GET Alpha Random Employee

Response body:
------------------------------------
{
    "age": "9999",
    "name": "Artemis",
    "power": [
        "immortal",
        "srtong"
    ],
    "email": "customer.service@olympus.com"
}
------------------------------------


Delete the Plugin for the next lection.






51. Correlation ID
==================

This plugin will transform the request and response by adding a new header. The new header will be passed along from Kong to the backend service and sent back to the client response. The new header can be used to track one request to one response.

The common case for this is for logging.

The client can send a request through Kong, where the backend logs the required items, using correlation ID as the key - correlation-id.png

Configure Correlation ID Plugin
-------------------------------

Go to Kong Manager http://localhost:8002/services / Alpha / Plugins / + New Plugin / Correlation ID
	- generator: uuid
	- echo_downstream: checked			# the client will also get the same X-Correlation-ID header
	- header_name: X-Correlation-ID			# we can use custom header names
	- Install
